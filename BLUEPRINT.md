# KDramaWorld — Build Blueprint

**Everything needed to rebuild this site from scratch: stack, data model, design system, routes, and the decisions behind them.** Written for the day you (or an AI) want to build it again, build something like it, or extend it. The README covers the same project as documentation *of* the build; this file is a spec *for* building.

Site: **KDramaWorld** — "Some stories never leave you." A full-stack Korean-drama archive: discover dramas, keep a private journal, rank them, publish lists, and get a rule-based *Midnight Watchlist* recommendation when you cannot decide what to start at 1am.

---

## 1. Stack

| Layer | Choice | Notes |
|---|---|---|
| Framework | **Next.js 15 (App Router)** + React 19 | All pages are server components; `force-dynamic` where data is live. |
| Language | TypeScript (strict) | `npm run typecheck` = `tsc --noEmit`. |
| Styling | **Tailwind CSS 3** + a large hand-written `app/globals.css` of component classes | Tailwind for layout utilities, CSS custom properties for the theme. |
| Database | **PostgreSQL** (Supabase in prod; embedded Postgres locally) | Raw SQL through a tiny tagged-template wrapper (`lib/db/client.ts`) — no ORM. |
| Auth | Hand-rolled: scrypt + per-user salts, session cookies (`httpOnly`, `sameSite=lax`, 30 days), HMAC-hashed tokens in `sessions` | `lib/auth.ts`. |
| Images | `next/image` with self-hosted artwork under `/public/art/` | Posters/backdrops stored as files; TMDB artwork credited in `data/art-credits.json`. |
| Fonts | Self-hosted WOFF2, subset: **Cormorant** (display serif) + **Inter** (body sans) | `lib/fonts.ts`, regenerated by `npm run fonts`. Korean titles use the system Korean face (`--font-korean` → Noto Serif KR stack). |
| Tests | **Vitest** (395+ tests), node env, DB-backed via `TEST_DATABASE_URL` | `npm test`. |
| PWA | Manifest + service worker (`/sw.js`), install prompt nudged on `/` | `components/pwa/pwa-provider.tsx`. |
| Deploy | Vercel + Supabase | `npm run build` ≈ 19 s, First Load JS ≈ 103 kB shared. |

**Commands:** `npm run dev` · `npm run build` · `npm run start` · `npm test` · `npm run typecheck` · `npm run db:migrate [-- --reset]` · `npm run db:seed` · `npm run db:audit` · `npm run fonts` · `npm run icons`.

## 2. Design system

### 2.1 Colour (Ink theme, dark-first)

RGB-triplet custom properties so any alpha can be derived (`rgb(var(--bg-surface) / 0.9)`):

| Token | Value | Use |
|---|---|---|
| `--bg-base` | `8 11 20` | Page background (near-black navy). |
| `--bg-surface` | `13 18 32` | Cards, panels. |
| `--bg-elevated` | `18 26 42` | Raised surfaces, image placeholders. |
| `--bg-hover` | `25 35 55` | Hover fill. |
| `--text-primary` / `--text-secondary` / `--text-muted` | `247 245 252` / `180 188 208` / `127 138 163` | Ink → ink2 → ink3 text tiers. |
| `--accent-primary` | `232 121 197` | Rose (links, focus rings). |
| `--accent-secondary` | `155 138 251` | Lavender. |
| `--accent-champagne` | `128 201 244` | Champagne highlight (scores, active states). |
| `--success` / `--warning` / `--error` | `85 214 165` / `245 196 107` / `217 121 121` | Status. |

A light **Daylight** theme flips the scheme (`html.theme-day`, `color-scheme: light`) via the same tokens. A drama page overrides four `--drama-*` tokens (`tint`, `glow`, `deep`, `muted`) sampled from that drama's own artwork, so **each drama's page is painted in its own colour** — one background for the whole document, no section paints its own.

### 2.2 Type

- Display: **Cormorant** (`.display-lg`, `.display-md`…) — titles, shelf headings, hero words.
- Body: **Inter** (`--font-sans`).
- Korean: system stack via `.korean` / `--font-korean`.
- Eyebrow labels: 9–11 px uppercase, `tracking-[0.12em]`, muted — the archive voice.

### 2.3 Layout — the rail

**Every page is the width of the window.** No centred column anywhere.

- `--page-gutter: clamp(1.15rem, 4vw, 3rem)` — defined once on `:root`.
- `.shell` and `.shell-wide` are the *same* rule: `width: 100%; max-width: none; padding-inline: var(--page-gutter)`. The header, the footer, every page, the home hero, the auth stage and the drama page's `--drama-gutter` all read the same number.
- `--nav-h` fixes the sticky header height; hero top padding is `calc(var(--nav-h) + 56px)`.
- Mobile: fixed bottom tab bar (`lg:hidden`), content unaffected.
- Pinned by `tests/full-width.test.ts` (fails if any page reintroduces a `max-w-*` container).

### 2.4 Signature components

| Component | What it is |
|---|---|
| `WorldHero` (`components/home/world-hero.tsx`) | Full-height home hero: rotating backdrops (auto every few s), title + description **bottom-left**, glass facts card flush right (more transparent, smaller), heart top-right, no attribution/Share, no "hand-written catalogue". |
| `DramaPosterCard` (`components/drama/poster-card.tsx`) | The poster card everywhere: poster frame, score chip (source-labelled, never blended), quick actions on hover, status badges. |
| `DramaHero` + `DramaHeroBackdrop` | Drama page hero: rotating stills full-bleed; hero copy and facts on the rail. |
| `DramaEpisodes` / episode rail | Horizontal episode cards, **no scrollbar**; arrows fade in on section hover; keyboard-focusable. |
| `DramaCast` | Cast as **portrait cards** (3:4), never round avatars. |
| `Pagination` (`components/ui/pagination.tsx`) | Numbered pager + summary line: "Showing 1–48 of 2,503 actors · Page 1 of 53". |
| Loading skeletons | Route-level `loading.tsx`, page-shaped (hero block + card grid), no "Opening the archive…" animation. |
| `EmptyState`, `SectionHeading`, `ThemedSelect` | Shared UI primitives (`components/ui/primitives.tsx`). |

### 2.5 Standing visual rules (user-set)

- Reference: *Queen of Tears* hero → glass facts card look.
- All backdrops rotate automatically every few seconds.
- Hero height = available viewport; content must not be pushed far down.
- Favourite = heart icon only, top-right.
- No stills gallery section, no "Your journal" on the drama page.
- One background colour per drama page, drawn from its artwork.

## 3. Data model (Postgres, 8 migrations in `supabase/migrations/`)

**Catalogue:** `dramas` (slug, title, original_title, alt_titles[], synopsis, poster_path, backdrop_path, year, episode_count, network, external_rating + source/count, popularity, provider, metadata jsonb) · `genres` / `moods` + `drama_genres` / `drama_moods` join tables · `people` (actors/directors: slug, name, korean_name, portrait_path, height, birth/death) · `drama_cast` (person ↔ drama, characters, role, order) · `drama_backdrops` + `actor_gallery_images` (fetched stills/portraits with source credit) · `drama_ratings` (per-source scores) · `editorial_collections` + `editorial_collection_items` · `app_settings` (featured drama, mood activation).

**User data:** `profiles` (username, display_name, bio, avatar_url, is_public, role) · `sessions` · `user_drama_status` (watching/completed/plan…) · `user_ratings` · `favorites` · `favorite_actors` · `reviews` · `personal_notes` · `emotional_damage` (5-level scale) · `second_lead_entries` · `custom_lists` + `custom_list_items` · `rankings` + `ranking_entries` + `ranking_likes` · `activity_events`.

Row Level Security is enabled (see `0002_rls.sql`); the app talks to Postgres as a service role and enforces privacy in queries (private/unlisted content is never exposed, never sitemapped).

**Seeding:** `npm run db:seed` loads the committed catalogue in `data/` (≈1,352 dramas; 49 fully-curated with real metadata, the rest Wikipedia-sourced). Demo-mode entries carry a `DemoTag`.

## 4. Routes (all App Router, `app/`)

| Route | Purpose | SEO |
|---|---|---|
| `/` | Home: hero, quick discovery, journey shelf, top rated, forward slate, genre/actor tiles, editorial shelves | canonical `/` |
| `/discover`, `/explore`, `/top-rated`, `/upcoming` | Browse with facets (genre, mood, year, rating, network, episodes, view) | canonical to plain path |
| `/genres`, `/genres/[slug]` | Genre shelves / one genre browse | canonical own path |
| `/actors`, `/actors/[id]` | Actor index (48/page, numbered pager + summary) / actor page with credits, gallery, collaborators | canonical own path |
| `/search` | Full-text search (titles incl. Korean, cast, genres) | noindex, follow |
| `/drama/[id]`, `/drama/[id]/episodes` | Drama detail (hero, episodes, cast, reviews, related) / episode guide | canonical own path |
| `/watch/[id]` | Streaming theatre | noindex (editorial `/drama/*` is the indexable face) |
| `/lists`, `/lists/[slug]` | Public + editorial collections | canonical own path |
| `/rankings`, `/rankings/[id]`, `/rankings/new`, `/rankings/[id]/edit` | Community rankings | public ones canonical; forms noindex |
| `/emotional-damage`, `/second-lead-syndrome`, `/midnight-watchlist` | Signature features | canonical own path |
| `/my-collection` (+ `/watchlist`, `/[status]`, `/notes`, `/reviews`), `/my-lists` (+ `/new`, `/[id]/edit`), `/settings`, `/admin` | Signed-in screens | noindex + auth redirect |
| `/profile/[username]`, `/wrapped/[year]` | Public profile wall / personal recap (share links `?share=1&u=`) | canonical own path |
| `/login`, `/signup`, `/about`, `/offline` | Auth, about, PWA offline | login/signup/offline noindex |

`app/api/discover/count` powers the "Apply Filters (N results)" button through the same filter reader (`lib/discover-params.ts`) so the number never lies.

## 5. Data sources & sync

- **Wikipedia** — the base catalogue (`scripts/parse_wikipedia_list.py`).
- **TMDB** — posters, backdrop galleries, actor portraits, popularity (`scripts/fetch_tmdb_art.py`, `art:link`, admin importer). Credits recorded in `data/art-credits.json`; artwork status tracked per drama; a title with no artwork gets its fetch scheduled after first render (`scheduleArtworkRefresh`).
- **OMDb** — IMDb ratings + episode guides (`fetch-ratings-omdb.ts`, `lib/metadata/omdb-episodes.ts`); episode pages only sitemapped when OMDb is configured.
- **TVMaze** — supplementary metadata (`sync-tvmaze.ts`).
- **Ratings are never blended**: each score carries its source label (IMDb / TMDB / …).

### The artwork rule (posterless titles)

Titles with **no poster and no backdrop** (117 of 1,352 today) are real catalogue entries:

- **Never shelved on the home page** — every home query filters `hasArtwork` (`lib/db/home.ts`, home shelves in `app/page.tsx`, editorial previews skip them).
- **Sorted to the very end of every browse** (`artworkLast` ordering in `queryDramas`, applied by `lib/discover-params.ts`) — they land on the *last page* of `/explore`, `/discover`, `/top-rated`, `/upcoming`, genre pages.
- **Always findable by search** — `/search` applies neither rule; you asked for the title by name.
- When TMDB artwork arrives, titles return to normal placement automatically.

Pinned by `tests/artwork-ordering.test.ts`.

## 6. SEO (what "according to SEO" means here)

- **Canonicals**: every route declares one or is `noindex` (see table above). Filters/sorts canonicalize to the plain address; `/actors?page=N` self-canonicalizes (page 1 = `/actors`). `metadataBase` resolves per request, so tags match the served domain. Pinned by `tests/seo.test.ts` (walks every `page.tsx`).
- **Meta**: every page has `<title>` (template `%s · KDramaWorld`) and a meta description — blank synopses fall back to a real sentence, never an empty tag. Open Graph + Twitter cards on content pages, share image = the drama's own still.
- **Images**: all 57 `<Image>`/`<img>` sites carry descriptive alt text (`Goblin (2016) Korean drama poster`, `IU as Jang Man-wol`, `Episode 3: …`); decorative layers sit in `aria-hidden` wrappers. `sizes` set everywhere; hero uses `priority`, rails use lazy 480 px variants.
- **Sitemap** (`app/sitemap.ts` → `lib/seo.ts`): all public dramas, credited people, active genres, public lists/rankings/profiles with DB-backed `<lastmod>`; host-aligned, XML-escaped, capped under 50 k URLs; zero-downtime fallback to `data/` when the DB is unreachable.
- **robots.txt** (`app/robots.ts`): RFC-9309, points at the sitemap; `/watch`, `/search`, auth routes excluded.
- **Icons**: full favicon set + `manifest.webmanifest` so Google shows the logo, not a globe.
- **Verified by crawler** (`/tmp/browser/site-check.mjs` pattern: crawl seeds + all sitemap URLs, follow every internal link, load every image): 0 broken links across 575 pages + 1,494 sitemap URLs, 0 broken images, 0 missing titles, 0 missing canonicals, 0 slow (>4 s) pages.

## 9. Non-negotiables (the project's own rules)

1. **Never invent data** — no fabricated synopses, episodes, scores or airing status; missing facts are shown as missing.
2. **Ratings always name their source** — never blended.
3. **Privacy by default** — journals/notes private; private content never queried into public pages or the sitemap.
4. **One rail, full width** — no page returns to a centred column.
5. **The counts must not lie** — result counts, pager summaries and "Apply Filters (N)" all come from the same query the page runs.
